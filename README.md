# 🐴 Clases de caballo

Calendario para marcar los días de clase de caballo:

- 🟢 Tejero
- 🔵 Rocío
- 🩷 Competición
- 🟡 Adri sola
- 🔴 No avisaron

Y, compatibles con las anteriores:

- 🟣 Herraje de Robinna
- 🟤 Herraje de Cornelios

Las marcas se guardan en el propio móvil. Usa el botón **Copia de seguridad** de vez en cuando para no perderlas.
